## Brief

Keep the lazy-table implementation and repair recursive foreign-key resolution.

and retain its foreign-key metadata. Failed callbacks must still fail every retry.

## Changes

reads the table without invoking the same callbacks again. Keep the failure cache
ahead of the empty-list check so a failed export never passes on retry.
