## Teach

An ORM table is a list of columns plus extra config, such as indexes, foreign keys and access policies. Before this PR, every table built all of that as soon as its module loaded, so a function that touched two tables still paid for two hundred.

Now each table builds when something first reads it. A query builds only its own table, and pushing the schema or running codegen builds every table, so a broken definition still fails before deploy.

Building late means a column builder that several tables share must never be changed in place. The review found one spot that did: a discriminator made a shared required field optional in another table. Each table and discriminator now gets its own copy.
